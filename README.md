# HopRide Full Rider App

Complete rider app for **A2B Rides / HopRide**.

Riders can hop on and place **instant** or **scheduled** ride orders across Northwest Ohio & Southeast Michigan.

## Features
- Instant ride requests with simulated driver matching
- Scheduled rides (date + time)
- Vehicle options: Hop, Tesla Navigator, Hop XL
- Transparent fare estimates
- Current location, saved Home/Work places
- Ride history with cancel
- Live tracking simulation with progress steps
- Profile with saved places
- Black & gold holographic branding
- Mobile-friendly with bottom nav

## Tech Stack
Next.js 14 (App Router) + TypeScript + Tailwind CSS

Ready for:
- Supabase (auth, realtime, DB)
- Stripe payments
- Google Maps / Mapbox
- Capacitor for native iOS/Android

Built for the A2B Rides NW Ohio launch. Driver-first. Local focus.
